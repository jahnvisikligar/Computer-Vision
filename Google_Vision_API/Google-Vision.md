# Google Vision for Logo detection

This code leverages the Google Vision API to detect logos within an image file. It annotates each identified logo with its description and confidence score, providing valuable insights into the recognised brand elements. It also improves interpretability by visualising the detected logos with bounding boxes drawn from the provided vertices, making their spatial locations in the image easier to understand.
